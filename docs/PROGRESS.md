## Design notes per screen (PSY-16)

- **Tab bar**: shaped by PSY-07 (the object is the hero) and PSY-05 (ritual over habit loops). Unlike a generic app because it is a low, square-cornered slab of smoked glass with lacquer objects for icons, a soft glow under the active one and no badges or counters, not a stock navigation bar.
- **Today (empty)**: shaped by PSY-08 (language of the house). Unlike a generic app because it speaks in one catalogue-style line, 'Nothing worn yet.', with a calendar object set on grain, instead of an illustration and a call-to-action button.
- **Vault (empty)**: shaped by PSY-01 (discretion is the luxury). Unlike a generic app because the empty vault is a closed lacquer door with a dial and a promise of privacy, so absence feels held back rather than broken.
- **Society (empty)**: shaped by PSY-02 (earned, never bought) and PSY-08. Unlike a generic app because the Oxblood crest appears with no price, offer or urgency, and the headline is the brand's own phrase, 'Membership by invitation.'
- **Wanted (empty)**: shaped by PSY-08. Unlike a generic app because the copy is brief and courteous ('Nothing sought.') and the bookmark object stands alone with generous space.
- **Me (empty)**: shaped by PSY-09 (safety you can feel) and PSY-01. Unlike a generic app because it opens with the plain statement 'Your profile is sealed.' and a wax-seal style object, putting privacy first.

## Notes

- freezed is pinned to 4.0.0-dev.3 because riverpod_generator 4.0.9 requires it; revisit when freezed 4 is stable.
- riverpod_lint is not installed: it conflicts with freezed_annotation 3 in the current resolver. very_good_analysis covers the lint requirement.
- Android licences are not accepted on this machine (flutter doctor --android-licenses) and Chrome is not installed. Both are needed before Android emulator runs and Lighthouse checks.
- iOS deployment target raised from 13.0 to 16.0 because Xcode 27 rejects targets below 15.0. flutter build ios --simulator fails here (engine framework lacks x86_64); use flutter run -d <simulator>.
- DS-03 is Partial: token pairs pass AA in both themes; screens are re-checked once they exist.
- ENG-02, 03, 07, 08, 09 are Partial: scaffold and CI exist; repositories, Riverpod features, Server Actions, Edge Function tests and goldens arrive with later phases.
- Fraunces and Inter Tight are bundled as variable fonts under the OFL (licences in apps/mobile/assets/fonts). Neither has a small-caps feature, so labels are uppercase with wide tracking (SPEC 3.2 equivalent). Inter Tight supplies tabular figures; Fraunces has none, so numerals use the text face.
- Goldens use a 1% pixel tolerance (test/flutter_test_config.dart) because font rasterisation differs slightly between macOS and Linux CI.
- The five tab screens are designed empty states (UX-01) in the house voice. Their content arrives in phases 2 to 6; they are not placeholders for missing navigation.
- AppIcon draws placeholder 3D-style glyphs with CustomPainter (SPEC 3.3). Final Blender renders and Rive files replace them behind AppIcon in phase 10.
- Display type scales to at most 1.25x and tab labels to 1.2x so words never break mid-word at the largest text size; body text scales fully.
- psDrawerTransition (NAV-02) and the reduced-motion crossfade are built and tested; they are wired to real routes when bottle detail exists in phase 2, so NAV-02 stays Not started.
- ENG-06 (60 fps on mid-range Android, cold start under 2 s) is unmeasured. It needs a physical Android phone; the BackdropFilter tab bar is the thing to profile first.
- Phase 0 commit hashes remain valid: those commits were pushed to main directly and are in its history. Phase 1 rows cite the pull request because the squash merge creates a new hash.
